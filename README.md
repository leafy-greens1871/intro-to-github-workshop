# Introduction to GitHub Workshop

A beginner-friendly, hands-on workshop for learning the basics of GitHub.

**Duration:** 1 hour 15 minutes  
**Level:** Beginner — no prior experience required

## What You'll Learn

- What Git and GitHub are and why they're useful
- How to save and track changes to your work
- How to use branches to work without breaking anything
- How to propose changes using pull requests

## Setup (Do This Before the Workshop)

1. **Create a GitHub account** at [github.com/signup](https://github.com/signup) (free)
2. **Install Git** from [git-scm.com/downloads](https://git-scm.com/downloads)
3. **Install VS Code** from [code.visualstudio.com](https://code.visualstudio.com/)

### Verify Git Is Installed

Open your terminal (Mac: Terminal app, Windows: Git Bash) and run:

```bash
git --version
```

You should see something like `git version 2.x.x`.

### Configure Git

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```
