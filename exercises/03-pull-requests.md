# Exercise 3: Opening a Pull Request

## Goal

Propose your branch's changes by opening a pull request.

## What's a Pull Request?

A pull request says "I made some changes — can you review and merge them?" It's how people collaborate on GitHub.

## Steps

### 1. Go to the Repository on GitHub

You should see a banner saying your branch was recently pushed. Click **Compare & pull request**.

If you don't see it: click **Pull requests** tab → **New pull request** → select your `add-YOUR-USERNAME` branch.

### 2. Create the Pull Request

- **Title:** "Add contribution from YOUR-USERNAME"
- **Description:** A sentence about what you added

Click **Create pull request**.

### 3. Explore Your PR

Notice:
- The **Files changed** tab shows exactly what you modified
- Others can leave comments and suggestions here

## Key Takeaway

Pull requests let you propose changes, get feedback, and keep a history of what was changed and why.
